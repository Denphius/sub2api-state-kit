# 插件版验证记录

对象：STATE Kit 插件 `0.3.0`，官方 Sub2API `v0.2.7`（`aea725f2ea644d5592d0bbb1d63b607efa7e200a`）。插件源码、UI 和发布者签名均属于本项目；没有运行或复制用户提供的私有传输插件。

## 验证层次

1. **后端自动化：** 默认关闭、账号隔离、Pro / Team 筛选、采集与固定出口复验、持久化恢复、失败续期保留旧票据、异常守护、取消与并发。
2. **网页自动化：** 沙箱消息来源和 Token 校验、超时、加载/保存、账号默认关闭、参数校验、只读状态刷新、未保存修改保留及敏感字段遮挡。
3. **官方宿主集成：** 使用官方安装器加载真正的签名 `.s2plugin`，启动独立进程，与宿主通过 gRPC / HostService 通信，再转发本地可控上游。
4. **原生 Linux：** CI 在 amd64 和 arm64 上下载待发布的同一个签名包，验证哈希/签名，与当前源码的可复现构建比对，并运行官方宿主集成。

## 本地执行结果（2026-09-19）

- `go test -race ./...`：通过；覆盖 27 个后端顶层测试及其子用例。
- `go vet ./...`：通过。
- `node --test ui-tests/*.test.cjs`：15 项通过。
- 官方 0.2.7 宿主安装器及真实子进程集成：在 macOS arm64 上通过，包括未知发布者、篡改载荷和篡改签名拒绝；原始转发、SSE 逐帧传递/取消、反向账号目录与 KV、启动/关闭/重启。
- 网页：在真实浏览器的 `sandbox="allow-scripts"` 模拟宿主里验证添加账号、Pro/Team 选择、保存，以及自动轮询保留未保存输入。修复了沙箱禁止原生表单提交造成的保存失效问题。页面使用模拟账号 ID，没有真实账号或代理。
- 隐私：新增源码、UI、说明与已提供的 6 份私有账号/代理导出进行实际值比对，未匹配到其中的敏感字段。发布只收集明确允许的源码/静态资源和本次编译程序。

## 不包含在这轮验证中的内容

- 没有使用作者的真实 OAuth 账号、代理池或生产服务验证这次插件是否恢复了模型路由。
- 控制上游模拟了成功、模型不符和异常 STATE；测试通过证明本地采集/验证/注入逻辑按这些输入工作，不证明上游一定返回可用票据。
- 没有生产流量压测、长达一小时的真实上游有效期保证或多副本协同结论。
- 宿主接口只支持独立插件配置页；不会自动迁移源码版的账号设置、票据，也不会把控件插进原账号编辑页。

用户原有的真实测试实例与生产环境不参与上述隔离测试。正式包默认 STATE 关闭、账号配置为空；不打包私有运行数据或签名私钥。
